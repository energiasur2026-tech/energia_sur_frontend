# Sonidos, horarios y unidades · 11/11/2026

Lumi genera tonos originales con Web Audio, sin archivos externos ni micrófono. Cues distintos para abrir/cerrar, seleccionar, enviar, recibir respuesta, pregunta pendiente, sugerencia, aviso eléctrico, guardado y error. El contexto se crea/reanuda solo después de una interacción. Sin API compatible o con autoplay bloqueado, la UI sigue funcionando sin audio.

Preferencias → Sonidos de Lumi permite silenciar y probar. soundsEnabled es un booleano persistido por usuario/medidor en settings; no requiere migración. Sin preferencia previa queda habilitado, pero no reproduce el historial inicial. Las actualizaciones iguales no repiten avisos. Preguntas proactivas pausadas no suenan. Pestaña oculta, cambio de contexto y desmontaje detienen el audio; los mensajes visuales permanecen disponibles. Volumen moderado y separación corta para evitar superposiciones. Las pruebas verifican la programación con un AudioContext doble, no sustituyen una escucha en el equipo del usuario.

Fechas de eventos/recuerdos: zona America/Argentina/Buenos_Aires explícita y ciclo h23; no dependen de la zona o preferencia 12/24 h del navegador. El evento de 941 W revisado en SQLite tenía at=2026-11-11T19:40:10+00:00: se muestra 11/11/2026, 16:40:10. No se alteraron instantes ni mediciones. Los mensajes nuevos incluyen offset UTC; los históricos de SQLite CURRENT_TIMESTAMP sin offset se entregan explícitamente como UTC. No se reescribieron sus filas ni se cambiaron hábitos/análisis de franja.

MonthChart agrega selector kWh / $ ARS. Es solo visual: conserva el objetivo y las líneas activas. El backend agrega chart.cost, convirtiendo cada punto con el mismo cuadro configurado que la proyección. Preserva null en huecos y no agrega cargo fijo a áreas. Objetivo en pesos mantiene el presupuesto ingresado incluso en discontinuidades de tarifa. Ritmo monetario es distribución lineal del presupuesto mensual. Con cargo fijo se muestra el equivalente mensual completo, no un cargo diario inventado. Toda vista monetaria es estimación del cuadro configurado, no una factura total ni garantía de vigencia. Sin tarifa válida o sin conversión recibida se deshabilita ARS. Los controles, tooltip, eje y descripción accesible cambian juntos.
